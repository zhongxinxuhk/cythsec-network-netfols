# 中间件配置与 Actions 接线验收

基线为 `1e23d8c`，分支 `codex/middleware-connection-config`。只修改配置入口和相关测试/CI 接线，
不配置生产服务地址或生产密码，不改变现有 CI 的任务依赖和最终成功门禁。

## 实现

- 版本化应用 JSON 与环境模板；ClickHouse 全部连接字段支持环境覆盖及显式 CLI 优先。
- 凭据支持环境变量或私有密码文件，加载到单个客户端并通过子进程环境传递，不进入参数/目标绑定。
- 指定配置缺失/无效、混用密码来源、非普通文件及错误连接范围失败，不静默改投默认服务器。
- 版本化独立测试配置；Compose 服务、健康探测、查询及写入器共用同一组测试变量。
- Actions 在 RUNNER_TEMP 生成 0600 环境文件和随机测试密码，先注册屏蔽，再注入当前任务。
- 普通 PR CI 不引用生产 Secrets；配置入口拒绝外部测试主机，密码不进入制品。
- 密钥兜底扫描只对 Compose 指定路径的纯环境引用放行；字面回退/拼接/越界路径继续阻断并有反向测试。
