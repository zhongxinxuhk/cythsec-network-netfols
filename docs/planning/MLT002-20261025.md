自证已实际执行：

1. 三个实际工具各接受一个合法正向样本。
2. Ruff 检出未使用导入（F401），Black 检出错误格式，mypy 检出不兼容返回类型（return-value）；**3/3 注入被检出**，不是只检查命令存在。

4. mypy 包含 C 源码/头文件：C++ 枚举现在精确排除 `ml/training/.venv`。自证调用实际 `lint-all.sh --list-cpp`，确认真实 C++ 源码仍被枚举，环境内 vendor.cpp 不被枚举。没有扩大为全仓裸目录排除。

该入口已挂入 `lint-all.sh`、默认 `test-all.sh`、lint workflow 和独立 Python CI job。CI 初始化显式同步 quality 分组，随后用同一离线入口。**远端 CI 未触发，不能写成远端通过。**
