## 本轮交付

- routerd / telemetryd 共用静态 Bearer 摘要策略，私有文件校验、启动失败关闭、服务端端点授权。
- 默认回环监听；无鉴权的非回环监听拒绝启动，非回环明文认证请求拒绝，伪造转发头不能放行。
- 真实 session 接口；只读角色禁止聚合导入，运维和管理员仅开放现有两项聚合写入，其余写入拒绝。
- Ant Design Pro 认证抽屉与 Ant Design 表单；服务凭据隔离且仅存页面内存，身份变化清空旧数据。
- 修复两种迟到响应竞态：旧 401 不撤销新凭据，旧匿名 session 的延迟响应体不清除新身份。
- 开发服务器实际监听地址约束；窄屏服务状态改为可聚焦的状态点与 Tooltip，避免页头文字被截断。
