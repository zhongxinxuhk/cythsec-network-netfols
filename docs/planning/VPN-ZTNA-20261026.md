# VPN / ZTNA 识别适配开发记录

日期：2026-10-26。分支：`feat/vpn-ztna-identification`。输入真源：
`docs/vpn_ztna_protocol_identification_2026.md`。本轮不推送、不执行外部主动扫描。

## 范围与判据

1. 核对输入手册全部 V/P/O 编号、承载/认证协议、国内与海外产品矩阵；组合项拆出子协议文档。
2. 每个目录项独立说明观测条件、结构/状态机、统计方法、主动验证、反例、验收和参考来源。
3. 标准协议实现有界解析；加密/私有协议实现上下文证据关联，禁止端口、熵、TLS 指纹直接归因产品。
4. 识别结果区分结构候选、双向确认、可信上下文关联、未知；不把目录覆盖冒充真实样本准确率。
5. 增加从真实 pcap 读取的可运行入口、截断/变异/错配/重传/预算回归与目录一致性门禁。
6. 更新 docs 索引、架构衔接、输入手册及验收记录，所有新增架构图用 Mermaid。

## 接口约束

- 保持 Rust 零第三方依赖、现有 FlowRecord/21 维特征契约及 ABI 不变。
- DPI 解析器保持纯函数；会话关联、TCP 重组、证据关联放在独立分析层。
- 主动探测规划与执行分开；无精确目标、期限、授权和流量预算时拒绝生成可执行计划。
- 厂商能力资料只能登记目录；可信终端/网关证据必须匹配实际五元组、时间窗和独立来源。
- 现有 WorkBuddy 和独立 Actions 分支不在本轮修改范围。
