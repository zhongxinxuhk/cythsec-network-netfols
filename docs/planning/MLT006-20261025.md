## 交付

- `ml/training/features/dataset.py`：可导入 API `build_bundle` / `validate_bundle`，以及 `python3 -m ml.training.features.dataset build|validate` CLI。
- 包观测 JSONL v1：一行一个带标识的非空包序列，从现有 Python 提取器计算；保留到达顺序与规范 A/B 方向。
- FlowRecord JSONL v2：按严格的 feature v1 键集合导出已有向量，行标识为 session_id；不从聚合记录伪造 IAT/熵。校验的是本项消费字段投影，不冒充完整 FlowRecord 协议验证器。
- `features.csv`：标识、首末时间、可选显式标签与按生成契约排序的 21 维数值。元数据与 label 不属于模型输入特征。
- `manifest.json`：来源标识、实际消费输入 SHA-256、实际生成绑定的契约指纹、行数、列顺序、CSV 摘要、标签状态/来源/摘要/类别计数。没有本机绝对路径或墙钟时间，同字节输入与相同配置产生逐字节相同产物。
- 标签只从显式标注文件连接；缺/多/重复/空标签均拒绝。无标签时不生成 label 列并声明 `labels.status=absent`，不会从 DPI、风险字段或特征值推断标签。
- 独占创建输出目录，先暂存并校验，最后发布完成清单；发布失败回滚本次新目录。下游必须先校验 manifest，不能把目录存在当成功。
- 逐行读入，单行限 16 MiB；重复标识与标签连接用临时磁盘 SQLite 索引。内存仍受行大小、类别数和解析器开销影响，不声称任意输入下恒定内存。

完整输入契约、使用命令与限制见 `ml/training/features/README.md`。
