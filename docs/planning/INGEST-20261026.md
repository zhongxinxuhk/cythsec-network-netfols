# 2026-10-26 聚合磁盘队列与常驻消费者

分支 `feat/aggregate-ingest-worker`，基线 `6c1dc57`。承接聚合本地持久化，本批新增可选磁盘待写队列、进程常驻消费、批次级恢复、指数退避和控制台积压状态。范围仍为通用承载、TCP 质量和采集完整性聚合结果。

## 交付

- 复用不可变 Store，队列落盘后返回 202，历史同步后才确认移除源文件。
- 至少一次重试，内容去重；SIGKILL／提交后确认中断可恢复。
- 有限队列、507 背压、1～30 秒退避，持久化或校验异常时显式阻断。
- 新增 `aggregate_queue_dir` 配置与 `/api/v1/analytics/ingest` GET／POST。
- 控制台显示积压、失败原因、重试时间和进程计数；不将入队确认当作历史保存。
- 修正批次时间字符串精度，以保证整秒与小数秒的排序和消费次序一致。

完整状态、Mermaid 数据路径和故障操作语义见 [队列契约](../observability/ingest-worker.md)。

## 验收

本地实现验证结果：lint 与四栈 build 实际退出 0；前端 9 文件／48 项通过（含状态请求超时撤销旧值），telemetryd race／vet 退出 0，aggregate 覆盖率 83.2%、api 87.6%；真实磁盘队列 SIGKILL／确认中断恢复与原存储 E2E 退出 0；四服务端到端 59 项通过、无失败或跳过。

初轮获批的完整门禁退出 0（当时前端 47 项）；超时修正后的普通用户完整门禁退出 **1**，唯一失败为既有 live 回读守恒式遗漏解析失败类别：572 帧 = 569 成功 + 2 不支持 + 1 解析失败，其中 1 个 IPv4 非首片分片。失败证据保留，不写成全绿。已由独立 `fix/live-readback-counts` 分支修复并通过最终完整复验，详见 [回读修复记录](LIVE-READBACK-20261026.md)。队列、前端和数据面解析算法未因该计数失败被修改。

当前账号已在 access_bpf 组，普通用户能采集。初轮提权复验为 494 帧／14 项通过，无可用网关、未执行 ICMP 注入。后续无需再提权。既有 DPI 14、重组 2、FlowRecord 8 项仍未核验，远端 CI 未运行。

最终结果：静态门禁退出 **0**，四栈构建退出 **0**，修复后普通用户完整门禁退出 **0**；9 个前端测试文件／48 项通过；真实持久化／队列恢复 E2E 通过；Go race／vet 通过；四服务端到端 59 项通过。最终 BPF 5037 帧、15 项断言通过（含新增离线自证），无网关、无 ICMP 注入，不使用 sudo。

## 限制

本批是本地有限容量队列，不是 ClickHouse 常驻写入；没有新增实时采集轮转生产者、开放外网鉴权、自动历史归档、Prometheus 队列指标或吞吐基线。生产者须提交完整聚合批次，不能将无尾记录的无限流当作成功接收。既有裁判例外仍需独立验收。

原有暂存改动保留，只提交本地功能分支，不推送。
