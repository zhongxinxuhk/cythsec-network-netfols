## 4. 页面统一验收场景

### 4.1 路由、菜单和范围

- 所有已发布路由支持直达、刷新、菜单切换、前进后退和404。
- 隐藏详情页高亮对应列表，面包屑返回能恢复原筛选和页码。
- 未发布能力没有生产菜单；已发布能力中途不可用时显示真实原因。
- 实例/身份/批次切换使旧请求失效；复制深链接不包含凭据或敏感原文。
- URL返回路径只允许应用内白名单，覆盖协议相对路径、反斜线和编码绕过。

### 4.2 只读显示和查询

- 每页有成功、空、初次加载、错误、未知、未支持、未启用、部分和过期测试。
- 图表与表格范围/版本一致；当前页、已加载集合与完整匹配范围有明确差别。
- 日期边界、时区转换、非法范围、分页越界和对象消失有反馈。
- 计数重置不产生负速率；没有测量前置条件时保持速率未提供。
- 表格和抽屉长文本不遮挡操作，所有关键字段可键盘访问。

### 4.3 聚合与完整性

- 同批次同口径窗口可按定义汇总；不同批次即使日期相邻也不自动合计。
- 整窗与子组抑制均保持null语义；贡献窗口/样本范围明示。
- TLS/QUIC保留头候选标签；TCP缺口与时差不升级为确定丢包率/网站时延。
- 来源丢包未知、声明零、声明非零和计数不一致有独立文案。
- input_complete、analysis_complete、历史保存和队列接收互不覆盖。

### 4.4 写入和后台任务

- 超1MiB、非法JSONL、缺尾记录、未知字段和安全整数越界被服务端拒绝。
- 只读身份禁止写入；UI禁用不是唯一防线，服务端越权用例必须403。
- 正常入队202后仍标历史未确认；对应ID可查询后才改为历史已确认。
- 重复提交不多计历史批次；写响应丢失先核对实际状态，不把重试当新业务成功。
- 队列挂起/超时清除旧0积压，未启用队列与请求失败不同。
- 未来保留策略预览过期、版本冲突、部分失败和保护对象均不能静默跳过。

### 4.5 身份与平台管理

- 无演示账号、默认管理员、假头像或静态成功会话。
- 服务凭据只发给所属服务，不存浏览器持久介质或URL，不进入日志/截图样例。
- 旧401和延迟认证响应不能撤销后来建立的新身份。
- viewer/operator/admin的当前能力与目标专门权限分开验证；未知能力默认不允许写。
- 未来账号禁用、范围修改、会话撤销和配置并发冲突有后端事实与审计。
- 日志、报告和错误文本作为数据解析，不能执行其中的命令或HTML。

### 4.6 布局与可访问性

- 1440/1920/1280/1024/768/390宽度检查，不仅检查开发机单一宽度。
- 主页面不横向溢出；大表格在独立容器内横滚，固定列不遮住最后一列。
- Tab/Enter/Escape可操作菜单、筛选、表格、抽屉、日期和连接表单。
- 表单标签、错误聚焦、关闭后焦点恢复、无颜色状态、减少动效均检查。
- 自动刷新不抢用户输入、阅读位置或当前批次；无尽加载不是未知状态的处理方式。

## 5. 自动化与人工验证边界

| 层 | 必做验证 | 不能替代的内容 |
| --- | --- | --- |
| 类型/静态 | 类型、ESLint、接口schema和安全依赖检查 | 不能证明后端或浏览器任务成功 |
| 组件/API测试 | 真实Ant/Pro组件，错误/超时/权限/迟到/确认阶段 | 不能将整个组件库mock掉后声明UI兼容 |
| 后端契约 | 真实请求、访问范围、版本、拒绝与持久确认 | 不能由前端按钮状态证明安全 |
| 浏览器 | 菜单/直达/回退/表单/响应式/控制台日志 | 截图不能证明存储、采集或转发完成 |
| 仓库门禁 | lint-all、test-all及实际退出码 | SKIPPED/未核验不算通过；不能只报脚本退出0 |
| 部署与性能 | 生产接入、容量与恢复独立证据 | 单机样本、当前设计或构建通过不能替代 |

单独核验；未执行的业务门禁不声明通过，未向生产部署，也不合入main。
