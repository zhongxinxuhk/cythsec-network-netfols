# 图形化可视化、视觉细节与页面组合

版本：1.1，2026-10-27。目标：面向网络与安全运维人员的高密度、可解释、可追溯界面。
保持Ant Design Pro官方组件；架构图用Mermaid，业务图表不以Mermaid代替交互可视化。
关联：[整体布局](layout-and-interaction.md)、[资产页](network-assets.md)、[联动页](security-integrations.md)。

## 1. 视觉方向与实现规则

默认浅色工作台，深色监控主题使用同一ConfigProvider官方算法。主色沿用Ant蓝，
青色用于观测系列、橙色用于待关注、红色用于明确失败；颜色不能独自承载含义。
保留专业设备界面的信息密度，但拒绝旋转地球、随机连线、无来源攻击地图、装饰性流光和伪实时数字。

| 元素 | 设计值与规则 | 实现 |
| --- | --- | --- |
| 外壳 | 顶栏56、侧栏224、内容24；同既有规范 | ProLayout，PageContainer |
| 视觉层级 | 20px页标题、16px区块、14px正文、12px辅助；指标28px | ConfigProvider Typography/Statistic Token |
| 间距 | 4/8/12/16/24/32；图表区之间24，控件之间8 | 业务布局CSS，不覆盖Ant内部结构 |
| 边角/阴影 | 遵循borderRadius与boxShadowSecondary；仅选中/浮层强调 | 官方Token，禁止另一套控件皮肤 |
| 摘要条 | 4项以内；数字+单位+时点+质量；不给无定义“全网安全分” | Statistic、ProCard |
| 查询区 | 时间/范围始终可见；次级条件折叠；已生效条件可清除 | ProForm/Ant控件 |
| 表格 | 默认25条；固定身份列和必要操作；数字右对齐 | ProTable，服务端筛选/分页 |
| 证据 | Tooltip短说明；Drawer长证据；来源/时间/方法并列 | ProDescriptions、Drawer、Timeline |
| 字体 | 系统中文无衬线；数字等宽特性；IP/MAC局部等宽 | 不下载外部字体；保留复制完整值 |
| 动效 | 筛选过渡100—200ms；不循环动画；遵守reduced-motion | 组件内建动效；图表关闭无意义过渡 |
| 图标 | 类型、操作、状态使用Ant图标；不能靠图标猜动作 | @ant-design/icons；按钮有标签 |

视觉稿用真实已安装React/Ant/Pro组件生成，合成数据有永久“设计演示”标识，
不接管理API。自绘SVG只表达图表和拓扑设计，不手绘按钮/输入/表格去模仿Ant。
实施时图表候选为Ant Design Charts，关系图候选为AntV G6；本轮不安装依赖、
不宣称它们已兼容当前React/Ant版本，待实现页做peer/锁文件/体积/安全核对。

## 2. 图表目录与点击语义

所有图表均携带scope、sensor/domain（如适用）、时间窗、metric_version、单位、质量和数据时间。
下表V01—V20为目标图表，不是现有API已提供的功能。

| ID / 图形 | 页面 | 数据/轴与计算 | 交互与替代 |
| --- | --- | --- | --- |
| V01 接口流量趋势 | P01/P09 | 时间×bps，收发分线；差分计数/实际dt，重置断开 | 框选时间联动表；显示原始计数；无dt不画速率 |
| V02 承载构成堆叠条 | P13/P01 | TCP/UDP/其他IP，bytes或packets单选；同口径相斥分类 | 点击系列筛选；表格列出值/分母/未知，拒绝混合候选重叠占比 |
| V03 TCP质量小多图 | P14 | 重传候选、缺口观察、RTT样本p50/p95/p99分图 | 共享时间光标；不把缺口当丢包率或RTT当应用时延 |
| V04 完整性状态带 | P16/P12 | 时间×输入/分析/丢失状态分类 | 点窗看证据；未知灰色斜纹，零丢失声明与未知不同 |
| V05 接入写入阶段图 | P19/P52 | 接收/校验/排队/保存计数及单位 | 点阶段查错误；非守恒阶段不画等量Sankey |
| V06 存储容量条 | P20 | used/allocated/available与采样时点 | 点卷查看；未提供total不算百分比 |
| V07 队列积压面积趋势 | P19 | 时间×待处理条数/字节分轴或分图 | 对照消费者状态；缺样本断线，不补0 |
| V08 受管基础设施拓扑 | P41 | 证据节点/类型边/方向/容量 | 图层、单跳、聚焦、范围搜索、表格替代；不随机补边 |
| V09 区域通信热矩阵 | P42 | source_zone×destination_zone，色深为log1p(bytes)可选 | 图例明确变换；单元显示原值；空/抑制/0分色形 |
| V10 区域流量Sankey | P42可选 | 同窗同观测域的zone→carrier，bytes守恒且类别相斥 | 最多8主类+其他；双向分图，不含重叠TLS候选 |
| V11 受管地址有效期带 | P38/P39 | 时间×绑定观察，时段而非个人在线时间 | 点时段看证据；租期断开、未知结束带问号 |
| V12 IPv4资源块 | P39 | 已登记前缀的分配状态，≤256块逐层聚合 | 点击进入子前缀；未知不等于可用，IPv6改前缀树 |
| V13 资产质量趋势 | P38 | 时间×受管接口bps/错误/RTT分面 | 指标切换不共用错误单位；显示数据源/采样/阈值来源 |
| V14 服务类别条形 | P43 | 受管服务观察数×类别 | 已核实/候选分段；点击筛表；端口数不冒充漏洞数 |
| V15 安全事件趋势 | P44 | 时间×去重后事件数，严重级别堆叠 | 点击窗查P45；重复次数独列，源断流标缺覆盖 |
| V16 事件类别横条 | P44/P45 | category×去重事件数 | 排序Top8+其他，显示覆盖范围；非“攻击成功”统计 |
| V17 事件证据时间线 | P46 | observed/received/confirmed/updated与来源 | 来源时钟与平台时钟区分；证据可键盘展开 |
| V18 联动任务阶段链 | P50/P51 | draft/queued/accepted/verifying/verified等 | 当前、已过、失败、未知明确；2xx不跳到已验证 |
| V19 连接器质量热图 | P48/P52 | connector×时间，状态或解析失败率可切 | 显示分母、最小样本门槛；无事件/无心跳分开 |
| V20 联动延迟分位趋势 | P48/P52 | 时间×ms p50/p95/p99，明确阶段 | 时钟不可比不计算端到端；histogram跨窗合并后重算，不平均p95 |

V01/P09只能在增加真实测量间隔后实现；当前累计计数API不能由一次请求生成趋势。
V08—V20需对应新增契约。V02—V04应优先复用当前单批次聚合字段，仍须逐字段核对。

## 3. 专业页面构图

### 3.1 运行概览

1440画布中侧栏224，主内容左右24，可用1168；24栅格间距16。
首屏次序：页头与时间→4项摘要→16/8流量趋势与协议构成→16/8拓扑摘要与数据质量。
告警/任务明细放下一个屏幕，不能为塞进首屏缩小到不可读字体。
概览每个区块可单独失败，整体不被单源错误覆盖成全绿；合成视觉稿中每块保留演示标记。

```mermaid
flowchart TB
    A[PageContainer：范围 / 时间 / 新鲜度] --> B[4项摘要：流量 / 受管资源 / 质量 / 待处理]
    B --> C[16列：接口收发趋势 | 8列：承载构成]
    C --> D[16列：受管拓扑摘要 | 8列：完整性和来源状态]
    D --> E[基础设施事件表 / 联动任务摘要]
```

### 3.2 拓扑工作区

工具栏固定在图内上方：图层、当前粒度、缩放、重置、表格替代。
左栏选择site/zone/类型，图上方始终显示“物理证据”“逻辑邻居”或“区域通信”之一。
节点选中出现焦点环；右侧显示稳定ID、管理范围、来源、有效期、指标、缺口与详情链接。
不显示全球地图作为默认背景。站点地图只有真实配置位置和聚合意义时才作为后续可选视图。

### 3.3 资产技术档案

左侧摘要固定宽度；右侧以Tabs管理密度，默认概要只放四维状态、小多图、地址证据与关联事件。
拓扑只显示一跳；时间带只显示技术绑定有效期，不命名为“用户在线轨迹”。
地址复制按钮保留完整值，但列表默认按asset.address.read权限决定是否可见；不伪造掩码真值。

### 3.4 安全设备联动

首屏用设备/连接器健康矩阵，三列“传输/解析/业务核对”并排，避免一个绿色圆点掩盖解析失败。
任务详情使用Steps表达阶段，Timeline表达每次投递与对账，ProDescriptions展示不可变快照。
失败信息旁直接给合规下一步：查看凭据引用、查看映射错误、对账、取消未投递任务；
没有能力的“重试”“回滚”“阻断”按钮不出现。

## 4. 图表通用行为

### 4.1 筛选与跨图联动

- URL只保存白名单范围ID、图层、指标与时间；不保存秘密或完整证据原文。
- 改动筛选先显示待应用，再查询；图表brush选择范围后可撤销，不暗中刷新全部页面。
- 同组图表共享query_context_id和as_of；不同快照标出，不在同一Tooltip里拼成一次观测。
- 轮询默认30秒目标、连续失败指数退避上限120秒、后台页签暂停；实施时服从实际API配额。
- 鼠标悬停显示值、单位、区间、来源、质量；键盘焦点提供同样信息。
- 图表选择为无副作用查询；任何外部投递都进入独立预览和任务流程。

### 4.2 图形中的缺失与异常

| 状态 | 画法 | 文案 |
| --- | --- | --- |
| 真零 | 正常轴上的0点或带值0的格 | 观察值为0，附分母 |
| 未提供 | 断线/灰格+问号 | 来源未提供 |
| 抑制 | 斜纹+锁定说明 | 小样本已抑制，不估算 |
| 不适用 | 空白区域+说明 | 当前接入方式不适用 |
| 超时/失败 | 区块错误，保留最近成功值并明显标旧/不可判当前 | 请求失败，最近成功于… |
| 过期 | 虚线/时钟图标+截止时间 | 观测已过期 |
| 部分 | 角标+范围覆盖条目 | 已覆盖x/y来源；其余未知 |

前后时间窗不同不能直接画“环比↑12%”；阈值线需policy_ref、版本、有效期和单位。
数据量TopN必须显示其他类和覆盖比例。饼/环图最多5类且相斥，不承担精细比较；优先条形。
事件点为同窗聚合数量，不能每点代表一台被攻陷机器。图表下载附时间/范围/质量/版本，禁止无标签截图流入报告。

## 5. 性能与无障碍预算

以下是设计验收目标，尚未压测。普通趋势每系列≤300桶，完整查询≤2000行；
拓扑初始80/160、展开300/600；矩阵默认≤12×12，最大24×24，超出先聚合。
大范围时间在服务端分桶；不从第一页数据算全量统计，也不把浏览器截图当数据导出。

1440/1920展开侧栏；1280保留两列但减非关键列；1024侧栏折叠；768图表单列、抽屉全宽；
390提供摘要+表格/列表替代，拓扑不强塞全图。移动端不展示复杂配置写入操作。
键盘可完成筛选、切Tab、选节点/行和打开证据；SVG/Canvas提供aria标签和结构化数据替代；
文字对比目标4.5:1、图形关键边界3:1，色觉模拟、200%缩放、深色和reduced-motion均需实施验收。

## 6. 可运行设计预览

源码：[preview.tsx](preview.tsx)、[preview.css](preview.css)、[构建脚本](build-preview.mjs)。
用已安装依赖构建到仓库忽略的`build/console-design-preview`；不修改生产路由、包清单或锁文件。

```bash
node docs/console-design/build-preview.mjs
python3 -m http.server 15176 --bind 127.0.0.1 --directory build/console-design-preview
```

端口被占用时换一个空闲本地端口，不终止其他服务。预览包含运行概览、拓扑、资产技术档案、
设备联动、事件调查5个代表视图，以及主题切换、选中证据、范围筛选和模拟任务阶段。
所有数据为固定合成值，示例IPv4使用文档保留网段、MAC使用本地管理地址；不读取实际流量/文件/秘密。
合成值不代表设备兼容、后端功能、真实容量或安全检测效果。预览不能发送通知或设备变更。
